Cambium

Politique de confidentialité · mise à jour le 21 novembre 2026

Cambium est un jeu pour apprendre à reconnaître les arbres. Il est conçu par Delphine Rousseau, qui en est l’éditrice. Cette page explique, simplement, ce qu’il advient de vos données quand vous jouez.

En bref

Cambium ne collecte aucune donnée personnelle. Il n’y a ni compte à créer, ni publicité, ni outil de mesure d’audience, et rien n’est vendu ni partagé avec qui que ce soit.

Ce qui reste sur votre téléphone

Votre progression (points, arbres adoptés, exercices réalisés, réglages) est enregistrée uniquement sur votre téléphone. Je n’y ai pas accès. Le jeu fonctionne entièrement sans connexion internet.

Pour effacer ces données, il suffit de désinstaller le jeu ou de vider son stockage dans les réglages d’Android.

Sauvegarde automatique d’Android

Selon les réglages de votre téléphone, Android peut sauvegarder automatiquement les données d’une application dans votre compte Google, afin de les retrouver si vous changez de téléphone. Cette sauvegarde est gérée par Google, selon sa propre politique de confidentialité. Cambium n’envoie rien de lui-même, et vous pouvez la désactiver dans les réglages Android (Google → Sauvegarde).

Les formulaires de contact

Le jeu propose de signaler un bug, une erreur ou un arbre à ajouter. Ces liens ouvrent un formulaire Google dans le navigateur de votre téléphone. Rien n’est envoyé tant que vous n’avez pas vous-même validé le formulaire. Dans ce cas, je reçois :

  • ce que vous avez écrit ;
  • la version de Cambium et le modèle de votre téléphone, pré-remplis pour m’aider à comprendre un problème (vous pouvez les modifier ou les effacer avant d’envoyer).

Ces informations ne servent qu’à améliorer le jeu. Le formulaire étant hébergé par Google, son fonctionnement relève aussi de la politique de confidentialité de Google.

Liens vers d’autres sites

La page « À propos » et les crédits renvoient vers les pages d’origine des images (Wikimedia Commons, notamment). Ces sites ont leur propre politique de confidentialité.

Enfants

Cambium ne demande aucune information, à personne, quel que soit l’âge.

Changements

Si cette politique change, la date en haut de la page sera mise à jour.
